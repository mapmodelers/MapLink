# Contributing

## Issues

When reporting a bug, include:

- your Unreal Engine, Blender and Windows versions
- what you did, what you expected, what happened
- the editor log (`<YourProject>/Saved/Logs/<YourProject>.log`) and the MapLink run log, or the output of **Copy Diagnostics**

## Security

Found a security problem? Report it privately to [support@mapmodelers.com](mailto:support@mapmodelers.com), not in a public issue.
